# ASTROs--V1 — Backend (Node + Express)

This project serves the existing static frontend and provides a minimal Express backend.

Run locally:

```bash
npm install
npm start
```

- `npm start` runs `node server.js` and serves static files from the project root.
- Use `npm run dev` if you have `nodemon` installed for automatic reloads.

API:

- `GET /api/status` — returns a JSON status object.
